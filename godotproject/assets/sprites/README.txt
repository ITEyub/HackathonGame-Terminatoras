Custom sprites
==============
Drop PNGs here to replace the built-in drawn art. Use the exported templates in
the sprites_export folder next to the project as your starting canvas:

- Keep the same canvas size (or any size with the same proportions / layout).
- Keep the feet on the same spot (bottom centre) so characters stand on the floor.
- Transparent background.

Names the game looks for:
  customer_round_front.png   customer_round_back.png
  customer_tall_front.png    customer_tall_back.png
  customer_wide_front.png    customer_wide_back.png
  cashier_back.png  cashier_front.png  boss.png
  burger.png  tray.png  winged_burger.png

Note: a custom customer PNG replaces that body type completely (the random colour,
hat and glasses only apply to the built-in drawn art). The example_*.png files in the
export folder just show the accessory variations.
